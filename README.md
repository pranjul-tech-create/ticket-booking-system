# 🎬 Ticket Booking System

A full-stack movie ticket booking web application built using React, Node.js, Express and PostgreSQL.

## 🚀 Features

- User registration
- User login
- Movie listing
- Show date and time
- Seat selection
- Seat booking
- Prevent booking already booked seats
- My Bookings section
- PostgreSQL database
- REST API

## 🛠️ Technologies Used

### Frontend
- React
- JavaScript
- HTML
- CSS
- Vite

### Backend
- Node.js
- Express.js
- REST API

### Database
- PostgreSQL
